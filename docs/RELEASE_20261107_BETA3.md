# YachiyoDesk v2.0.0-beta.3

Windows x64 桌面伴侣，提供 25 项内置动作与窗口边缘陪伴。

- 增加抱臂、较长舞蹈、抛掷、饮用、拿取、推物、交谈和电话动作，改善招手、开心、伸展与欢呼的节奏和身体随动。
- 窗口边缘陪伴支持坐下休息、跟随窗口移动、起身以及失去窗口支撑后的下落；保留拖放落地与屏幕边缘互动。
- 修正动画过渡、恒定轨道和动作结束后的手指姿态恢复，接触遵循材质实际可见表面。保留既有画质、衣发物理、角色导入和 AI 功能。

## 下载与更新

- `YachiyoDesk-2.0.0-beta.3-x64-Portable.exe`：便携版。
- `YachiyoDesk-2.0.0-beta.3-x64-Setup.exe`：安装版。
- `YachiyoDesk-2.0.0-beta.3-Models.zip`：两份免费官方 VRM 样例，包含作者、来源、使用条件与模型校验值。
- `SHA256SUMS.txt`：全部下载文件的 SHA-256 校验。

[前往 GitHub Release](https://github.com/earth34online/YachiyoDesk/releases/tag/v2.0.0-beta.3)。更新前退出旧程序，运行便携版或安装版；原有角色和设置继续沿用。官方模型包解压后在角色库导入并确认预览。

窗口坐姿使用：开启“桌面接触动作”和“站在窗口边缘”，把人物拖放到可见窗口顶边，落脚后在创作室 → 动作收藏选择“窗口边缘陪伴”。停止或播放其他动作会先起身，拖动和窗口失去支撑会解除坐姿。

新增动画来自 Quaternius 免费 Standard 原包，采用 CC0 1.0；重定向参考 pixiv/three-vrm MIT 实现，许可和来源随软件保留。没有分发 Desktop Mate 专有资源。程序采用 MIT；模型遵循各自作者条款。
