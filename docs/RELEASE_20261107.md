# YachiyoDesk v2.0.0-beta.2

Windows x64 桌面伴侣。此版固定原生 VRM 动作兼容性修复，并提供可免费导入的官方模型下载包。

## 本版变化

- 原生 VRM 自动校准手臂方向，修正待机反向举臂。
- 自然垂臂保留肘腕的放松姿态，亮掌依据实际手掌平面定向。
- 修正鞠躬方向和下蹲时手臂意外展开。
- VRMA 自然待机保留动画本身的手臂动作。
- 图形初始化失败时提供错误提示和重新载入入口。

## 下载

- YachiyoDesk-2.0.0-beta.2-x64-Portable.exe，便携版。
- YachiyoDesk-2.0.0-beta.2-x64-Setup.exe，安装版。
- YachiyoDesk-2.0.0-beta.2-Models.zip，AvatarSample_B 与 Seed-san 官方 VRM 模型及作者、来源、使用条件。
- SHA256SUMS.txt，全部下载文件的 SHA-256。

[前往 GitHub Release](https://github.com/earth34online/YachiyoDesk/releases/tag/v2.0.0-beta.2)

已有用户先退出旧实例，再运行新程序，角色资料和设置自动沿用。模型包解压后，在“角色库 → 导入 VRM 角色”选择文件，预览并确认。
