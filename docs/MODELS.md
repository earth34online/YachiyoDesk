# 可导入的官方模型

[v2.0.0-beta.2 模型下载包](https://github.com/earth34online/YachiyoDesk/releases/download/v2.0.0-beta.2/YachiyoDesk-2.0.0-beta.2-Models.zip)包含两个免费官方 VRM 文件，解压后在角色库导入并确认预览。

| 模型 | 作者 | 来源及使用条件 |
|---|---|---|
| AvatarSample_B | VRoid Project / pixiv Inc. | [原始文件](https://github.com/pixiv/ChatVRM/blob/b542aa00e19dccf9fc48ba340cf7eee011d2329a/public/AvatarSample_B.vrm)，[VRoid 样例条款](https://vroid.pixiv.help/hc/en-us/articles/4402394424089-VRoidPreset-A-Z)及内嵌 VRM Public License 1.0 配置 |
| Seed-san | VirtualCast, Inc. | [官方样例](https://github.com/vrm-c/vrm-specification/tree/94e82dd346fa6cf0337c4421728640e5252dd38e/samples/Seed-san)，内嵌 VRM Public License 1.0 配置，保留署名 |

模型下载包保留原文件，附作者、来源、SHA-256、使用条件及许可链接。导入、动画和物理均使用通用 VRM 骨架，模型文件没有加入角色动作特调。
