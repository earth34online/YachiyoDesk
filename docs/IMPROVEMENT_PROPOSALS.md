# 增强方案落实

> 2026-10-23：用户已确认当前运行正常，本版固定为维护基线。运行实现沿用 `1cc9620`，本轮不修改动作、物理或模型；穿模改进等待用户决定是否启动。当前状态见[固定基线记录](BASELINE_20261023.md)。下文较早日期的验证数字与交付过程保留为历史记录。


更新日期：2026-10-21。此前经审查进入 2.0 的方案已实现，功能说明见 [2.0 陪伴功能](COMPANION_2.0.md)，验证进度见 [开发记录](DEVELOPMENT_2.0.md)。

| 方案 | 2.0 实现 | 依据 |
|---|---|---|
| 可导入动作库 | 本地 VRMA 导入、播放、循环、停止、随机编排；可选自然待机 | [VRM Animation](https://vrm.dev/en/vrma/) 与 AIRI 的官方插件、局部髋部锚定和混合层 |
| 导入前预览 | 独立 worker 结构校验、真实运行时预览、确认入库、取消清理 | [glTF Validator](https://github.com/KhronosGroup/glTF-Validator) 与原有事务式角色导入 |
| 模型观察 | 多方向、动作、物理开关、恢复、截图与观察记录导出 | 真实动作、真实 profile 与物理路径；报告保留版本、模型资料和手工结论 |
| 本地配置快照 | 保存、导入、导出、差异预览、恢复前自动备份 | 复用 SettingsStore 字段校验和角色有效性检查，快照不含模型或密钥 |

上述是原四项方案；第三项需求中另外要求的新用户功能单独列出，不与原四项重复计数：

| 追加功能 | 用户操作 | 验证记录 |
|---|---|---|
| 桌面明信片 | 当前角色实景、背景主题与寄语，导出 PNG；可选调用自己的图像接口生成画作 | `runtime/result.json` 实际导出 |
| 生活小剧场 | 欢迎、舒展、晚安连续动作与对白，自定义对白，可中断 | `runtime-extended/result.json` 实际触发与中断 |
| 休息提醒 | 自定义间隔及提示语，角色动作提醒，可关闭 | `runtime-extended/result.json` 真实一分钟触发与关闭 |

验证记录位于 `artifacts/2.0-development-20261020`。三项本地操作无需 AI；图像生成等能力使用最终使用者自己的接口。

后台线程物理研究仍撤回，不属于已承诺或已接入功能。现有 PMX 原始物理继续在最终人体姿态后同步更新，不用上一动作的物理结果代替当前姿态。

2026-10-21 当前人物已完成校服接缝、上袖边缘及头部避让修复，并验证原始物理对应和持续运行。其后接入缺碰撞导入补全与用户 API 受限参数调整，经过真实预览流程验证。三类接触此前完成评估，最新授权后已加入功能；具体实现与边界见 [审查记录](REVIEW_20261021.md)。

2026-10-21 AIRI 物理对照采用官方 SpringBone/原始 PMX + Ammo、依赖更新顺序和动作混合，不将点选盒当作衣发碰撞。自动身体内接拟合与蒙皮修复为独立实现，不声称 AIRI 提供任意衣物的自动防穿模算法。已有有效配置优先，缺骨架或歧义输入提示完整来源。
