# v2.0.0-beta.4 · 桌面小道具与窗口躲猫猫

本版增加两种本地互动，保留原有 25 项动作、窗口坐姿、角色库与用户配置，无需 AI 接口。

- 创作室 → 桌面小道具：拿杯喝茶、从小桌拿起礼物再放回；原动作收藏中的饮用和拿取也会使用道具。可随时收起。
- 创作室 → 窗口躲猫猫，或角色右键 → 到窗口侧边躲猫猫：人物进入可见窗口的遮挡，从侧边探出两次，再回到原位。支持停止；窗口最小化、关闭或检测中断后恢复正常显示。
- 保持原有渲染质量和衣发物理。修正快速取消后迟到加载重新播放、分数 DPI 下移动尺寸漂移，以及背景窗口错误遮住探出区域的问题。

窗口互动需开启桌面接触和窗口边缘互动，并解除位置锁定。没有足够大的可见窗口时会明确提示；圆角、透明异形窗口按窗口矩形近似。道具按通用骨骼和实际尺寸适配，不修改原模型；宽大袖口仍可能遮挡持物。

下载本 Release 的 `Portable.exe` 或 `Setup.exe`；两者使用相同程序载荷。免费官方 `Models.zip` 继续提供 AvatarSample_B 与 Seed-san，并保留作者与许可。受限角色模型不随软件分发。

更新后继续使用原角色库和设置。便携版直接启动；安装版按向导操作。可用 `SHA256SUMS.txt` 核对下载文件。先前固定版本与标签保留。
