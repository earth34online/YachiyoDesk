## 操作

设置 → 通用 → 动作与更多设置，提供“桌面接触动作”和“站在窗口边缘”两个开关。前者控制拖放下落、落地缓冲和边缘停步；后者允许使用应用窗口顶边。默认启用，锁定窗口位置时停止位置接触模拟。

把角色拖到一个普通应用窗口上方后松手，双脚跨距范围内的可见顶边可以承接角色。角色站在窗口上时，自主行走范围限制在该段边缘内。窗口平移时角色跟随；顶边被其他窗口遮挡、最小化或关闭后失去支撑并落向下一可用表面。窗口上移到无法完整容纳人物的位置时释放支撑，避免头部被屏幕裁掉。

屏幕边缘按人物的可见范围判断，不使用透明窗口宽度。到边缘后停步、做近边手势并反向活动；手臂保持测得长度和柔和肘部，不强行伸长以够到不可达边界。点击、拖动和打开面板仍可中断动作；关闭窗口接触只移除应用支撑，桌面落地继续可用。

## 实现与保护

- `electron/desktop-contacts.cjs` 管理落体、支撑、遮挡区间、平台巡逻范围和中断。落体重力按角色屏幕身高换算，跨帧检测完整下降路径，避免穿过薄顶边。
- `electron/window-surfaces.ps1` 在独立隐藏进程中用 Win32/DWM 只读枚举顶层窗口，过滤自身、隐藏、最小化、cloaked 及桌面壳窗口。只返回句柄和矩形，不读取标题、文本或截图。
- `electron/window-surfaces.cjs` 将物理像素矩形通过 Electron `screenToDipRect(null, rect)` 转为 DIP。同一隐藏进程复用；无支撑时每秒两次读取，站在应用上时每秒二十次。退出、重载、隐藏或禁用时清理。异常停止检测并明确提示，桌面功能保持可用。
- PowerShell 无法访问 ASAR 内部文件，因此打包时把辅助脚本作为独立资源带入 `resources/window-surfaces.ps1`；源码运行仍使用原文件。
- `src/DesktopContactPose.ts` 在原有动画后、humanoid/节点约束/衣发物理之前叠加接触姿态。落地移动骨盆后对整条腿求解并保持原脚底位置；近边手势按相机和实际骨段求解，不编辑模型网格、衣物权重或原始模型。
- 接触取消不能释放真正的指针拖动所有权。面板打开暂停下降且不累计隐藏时间；隐藏与重载按生命周期清理，恢复时重新核对支撑。

参考接口：[Electron screen 坐标转换](https://www.electronjs.org/docs/latest/api/screen#screenscreentodiprectwindow-rect-windows)、[Win32 EnumWindows](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-enumwindows)、[DWM 窗口属性](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)。
