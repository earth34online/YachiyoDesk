## 已确认要求

- 用户自带 OpenAI 兼容 API，可自定义地址、模型，并按文本、视觉、识别、合成、图像生成分别配置；密钥只保存在使用者本机。
- 文字为主、语音可选；学习 AIRI 的服务适配、会话队列、上下文、流式取消、语音管线与角色联动。
- 导入失败后明确询问 AI 修复；显示发送内容并使用该用户自己的接口。修复在副本中进行，复验通过后才可导入；拒绝则停止并提示更换来源。
- 提供随程序分发的导入修复 skill，涵盖可修复问题与必须补齐来源的情形；生成贴图需要图像能力和明确同意。
- 实现动作库、导入前预览、可操作模型验收、配置快照及恢复。
- UI 精简文字、分组布局、清晰反馈，保留键盘操作与减少动态效果选项。

## 本轮关键修复

- PMX 物理不再反复回写动作控制的人体骨骼；刚体输出保留原始缩放并归一化旋转，消除长期单侧袖子放大。通用骨骼统一处理，不修改衣装模型。
- 录音取消按请求代际处理，晚到的授权和停止事件不能重新打开麦克风或关闭新录音；音频失败也释放 URL、设备与嘴形。
- 快照恢复尊重明确保存的角色比例表；普通缩放仍记住当前角色比例。
- 270° 观察按钮使用等价的 −90°，观察报告包含实际模型指纹、版本与物理路径；视觉结论由用户填写。
- 停止随机播放同时清除编排计时器；拖动、重置、手动动作会中断小剧场。冒烟测试按页面标识定位，不依赖标签顺序。
- AI 修复、真实预览与确认入库等待完整结束后再刷新角色库；取消会中止对应的转换或校验，晚到的预览不会重新打开。

## 验证口径

接口协议用本机 HTTP 服务覆盖实际请求、流式拆包、工具调用、失败及取消；商业服务的实测需要最终使用者配置自己的接口，不把模拟协议通过写成提供商实测。AI 修复不得执行模型返回的代码、命令或任意文件路径；结构检查和画面检查分别记录。既有角色、衣物物理和设置迁移持续回归。
