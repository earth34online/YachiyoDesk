# YachiyoDesk 1.0.9 · 1.x 收官版

日期：2026-10-20。公开版与桌面版共用核心实现，保留各自的角色资源；新增产品功能进入 2.0 规划。

## 本轮重点

- 通用 PMX 使用作者原始骨骼、刚体与关节，修正物理映射和重复驱动；四套服装共用同一实现，八千代保留专用路径。
- 行走、停步、转向、动作打断及拖动连续过渡；休息与唤醒平滑改变呼吸、头肩和眼睑，重置后新动作从正确姿态开始。
- 完善表情、姿态命中、设置预览、窗口恢复、转换重试和资源释放，保持原有画质与动作幅度。
- 参考 AIRI 的动作、MMD 物理和生命周期管理；详见 [适配依据](AIRI_REVIEW_20261020.md)。

## 验证

两份源码分别通过类型检查、38 个文件／260 项测试与前端构建；113 项共享内容一致。四套服装检查人体动作、连续行走、状态切换与关键动作八方向画面；八千代单独回归。实际解包程序检查首次引导、交互、隐藏恢复、行走中换角色、比例恢复、持续运行和多帧显示。自动人体指标与服饰画面分别记录。

兔女郎源包缺少两张贴图，独立副本用于骨骼和物理检查；正式导入仍明确提示缺图。旧角色没有可靠原始 PMX 的，重新导入完整源目录后启用新物理。
