# 桌面小道具与窗口躲猫猫

更新：2026-11-09。本文对应已交付的 [2.0.0-beta.4](https://github.com/earth34online/YachiyoDesk/releases/tag/v2.0.0-beta.4)。程序、正式 Release、四资产及日常入口已核对，见[本版交付记录](DELIVERY_20261109.md)；用户尚未进行 beta.4 最终视觉接受。beta.3 固定标签和包保留，历史交付见[原版记录](DELIVERY_20261108.md)。

## 操作入口

| 位置 | 操作 |
|---|---|
| 创作室 → 桌面小道具 | “拿杯喝茶”“拿起小礼物”“收起道具” |
| 创作室 → 窗口躲猫猫 | “开始躲猫猫”“停止并回来” |
| 角色右键菜单 | “到窗口侧边躲猫猫”“停止躲猫猫” |

小道具复用动作收藏中原有的“喝饮料”和“拿取桌上物品”，内置目录仍为 **25 项**。从动作收藏播放这两项也会使用对应道具。杯子和礼物是程序生成的三维物品，不控制桌面文件、实际饮料或其他应用。新功能无需 AI 接口，也没有新增外部依赖。

使用窗口躲猫猫前，开启“桌面接触动作”和“站在窗口边缘”，解除位置锁定。关闭创作室后，角色寻找足够大、侧边可见且能容纳人物的普通窗口，进入遮挡区域，隐藏后两次向侧边探出，再返回开始位置。没有合适窗口时明确提示。当前坐姿或落地动作未结束时先提示结束原动作；原有窗口顶边坐下、跟随、起身与失去支撑流程继续保留。

## 小道具如何跟随动作

`src/DesktopProps.ts` 管理物品、接触和资源生命周期；`MotionPlayer` 在既有动画流程中生成本次任务使用的片段，`AvatarRuntime` 在对应阶段更新道具和姿态。杯、礼物与小桌均由 Three.js 基础几何生成，尺寸依据测得的掌长、掌宽和角色缩放，不按衣服名称或角色 ID 特调。

杯子包含杯壁、杯口、茶面和把手。喝茶目标先根据头部、眼睛或颈部估计嘴部位置，再对头部蒙皮的实际可见不透明表面进行射线测量，过滤材质透明裁切与不属于头部的面；无法命中时保留骨骼估计。仅在本次喝茶任务的有效时间内，用双骨 IK 调整左臂与杯口接触，保持骨段长度，并连续淡入、淡出。该目标不成为普通待机、其他动作或衣物的全局手臂约束。

礼物先位于小桌上。程序在只包含骨骼的独立采样器中求出抓取接触标记，再在实际手部到达该标记附近时附着；不会从远处吸到手上。附着保留当时物品相对手部插槽的变换，避免标记处跳变。拿起、短暂停留后沿原抓取片段的反向路径放回。停止或替换动作会收起道具；退出时释放几何和材质，不修改原始模型、衣服网格或物理配置。

## 窗口遮挡与坐标

`electron/window-surfaces.ps1` 继续以只读 Win32/DWM 枚举获取窗口句柄及可见矩形，不读取窗口标题、文本、内容或截图，不调整外部窗口。`screenToDipRect` 将辅助进程返回的物理像素转换为 DIP，`electron/window-peek.cjs` 在 DIP 中计算可用侧边、人物位置和被窗口矩形扣除后的区域；裁剪只扣除目标窗口及其前层窗口，位于目标之后的背景窗口不会遮住侧边探出的部分。

绘制和输入裁剪使用本程序的 Electron `BrowserWindow.setShape`。Windows 路径由 `nativeRegion` 按当前显示器缩放将区域转换回物理像素；移动仍保持固定逻辑窗口尺寸，避免把原生回读尺寸重复换算后造成窗口或人物比例漂移。完全遮挡使用窗口范围外的小区域，结束后以空区域列表恢复正常矩形。人物探出时叠加局部侧倾、头部与视线动作，并暂时收起脚下阴影。

这是基于真实窗口边界的**矩形区域裁剪**，没有把人物窗口设置为外部窗口的真实后层，也没有修改外部窗口的 Z 序。Windows 圆角、透明或异形窗口仍按 DWM 矩形作保守近似，不保证其每个透明像素都与实际合成一致。

目标移动时更新几何；侧边被前层窗口遮挡、目标最小化/关闭/缩放、显示器变化、位置锁定、拖动、面板打开、设置变化、检测中断、锁屏、睡眠、重载或退出时，取消互动并清理计时器与裁剪。显示器变化继续走原有位置恢复与边界校正。取消与迟到的开始请求以代际隔离，避免取消后重新启动。
