# 动作与窗口陪伴

更新：2026-11-07。已确认的动作基线先以 v2.0.0-beta.2 完整发布并同步桌面，再进行本文的扩充。beta.2 标签和下载保持不变；新增实现的源码验证、画面与发布状态分别记录。

## 使用

进入创作室 → 动作收藏。内置目录共 25 项：招手问候、开心回应、惊讶、抱臂不满、困倦、轻碰回应、鞠躬、伸懒腰、随节奏轻舞、环顾、点头肯定、摇头拒绝、害羞、欢呼加油、托腮思考、下蹲、踮脚、轻轻摇摆、向前抛掷、喝饮料、拿取桌上物品、向前推物、自然交谈、接听电话、窗口边缘陪伴。

这些是 25 个用户可选动作，不将同一坐姿的进入/保持/退出片段或可选 AIRI 待机额外计数。原候选第 19 项曾重复使用第 25 项坐姿，用户明确否定后改为独立抛掷动作，旧复合坐姿文件不再分发。拿取、推物、喝饮料、抛掷和电话是动作展示，不会控制实际物品或电话。舞蹈持续 6 秒。动画文件可勾选循环；程序手势按本来的动作过程播放。用户自己的 VRMA 导入、删除与收藏继续保留。

窗口陪伴需要开启“桌面接触动作”和“站在窗口边缘”，关闭位置锁定。先把人物拖到一个可见应用窗口顶边的上方并松手，落脚后在动作收藏选择“窗口边缘陪伴”。面板收起后人物坐下并保持坐姿，跟随窗口平移；选择新动作或停止时先起身，再执行后续动作。拖动人物直接解除坐姿，窗口最小化、关闭或顶边被遮挡后重新下落。没有可用窗口支撑时明确提示，不在空气中凭空坐下。

## 来源与实现

- AIRI 的既有可选自然待机和局部髋部锚定继续保留。窗口互动借鉴 Desktop Mate 的公开行为，由本项目状态机独立实现，没有复制其专有代码、模型或动作。
- 新增外部动画来自 Quaternius 作者免费发布的 UAL1/UAL2 Standard 具体原包，包内和对应页面均为 CC0。来源、原包 SHA256、原 clip、转换结果分别保存在 `assets/motions/quaternius-provenance.json`；许可和署名文本随资源分发。
- 转换采用 pixiv/three-vrm 的 MIT Mixamo 示例公式与源 A_TPose 校准，按通用 humanoid 骨骼映射，不按角色名字或衣服添加调参。去掉源骨架非髋部平移和缩放，保留旋转与采样时间，生成纯 VRMA。
- 外部动画与程序动作共享连续进出层；固定轨道和保持最后一帧时，每帧重施动画样本，避免 Three.js 对恒定值的写入缓存被程序待机覆盖。无程序所有者的手指在退出后恢复基准，不残留上一段握手姿态。
- 坐姿保留作者相对髋部高度；窗口支撑由坐姿骨盆和通用骨段计算投影。垂脚超出站立原点时只平移镜头使脚部完整可见，不改变人物比例、动作幅度、画质或物理。
