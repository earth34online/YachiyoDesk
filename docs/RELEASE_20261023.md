# YachiyoDesk v2.0.0-beta.1

Windows x64 桌面伴侣，沿用已确认的 2.0 开发基线。公开程序不附带角色模型，请导入你有权使用的 VRM，或在本机转换并导入 PMX。

## 本版功能

- 使用自己的 AI 接口进行文字交流，可选语音输入、朗读和图片理解；本地功能无需配置 AI。
- 角色导入检查、真实模型预览，以及经明确同意后使用自己接口进行副本修复。
- VRMA 动作收藏、模型观察和设置快照。
- 桌面明信片、小剧场与休息提醒。
- 透明窗口、自主行走、拖放落地、屏幕边缘及可见应用窗口顶边交互。

## 下载与运行

- `YachiyoDesk-2.0.0-beta.1-x64-Portable.exe`：便携版，下载后直接运行。
- `YachiyoDesk-2.0.0-beta.1-x64-Setup.exe`：安装版，可选择安装位置并创建启动入口。
- `SHA256SUMS.txt`：两个程序包的 SHA-256 校验值。

从 [GitHub Release](https://github.com/earth34online/YachiyoDesk/releases/tag/v2.0.0-beta.1) 下载。已有使用者先退出旧实例再启动新程序；无需删除模型或配置。首次没有角色时，在角色库导入模型。

Windows 可能对未建立信誉的下载文件显示安全提示，请核对下载来源及校验值。PMX 转换依赖本机 Blender，配置方法见[安装与角色导入](INSTALLATION.md)。AI 能力需要使用者自己的相应接口；不配置接口仍可使用本地桌宠功能。

功能说明见 [2.0 使用说明](COMPANION_2.0.md)。本版固定范围见[基线记录](BASELINE_20261023.md)。
