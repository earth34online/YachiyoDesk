# YachiyoDesk 1.0.8

## 版本选择

以提交 `29595ad` 的 1.0.7 稳定主线为基础整理成品，保留通用 PMX 动作、首次导入引导、交互状态和角色管理的已有实现。此次版本统一为 1.0.8。

## 保留修改

- 衣物形状保护使用从原始蒙皮开始的连续允许区间，避免多个三角面的允许区间不连续时错误收回整件修正。增加刚体旋转、相邻允许区间、随机候选和非有限坐标检查。
- 身体表面的 BVH 最近点查询额外确认返回距离，避免超过搜索范围的叶节点结果被用作接触。
- 新增 `npm run sync:local` 和 `npm run sync:check`，统一两份项目的核心源码、测试、转换器、依赖、构建脚本和版本。验证流程自动检查同步。
- 公开包过滤本机 VRM、PMX、PMD 和 Blender 模型资产；桌面构建保留本地角色资源。
- 维护中的测试明确限定为 `tests`，构建前执行类型检查、测试、前端构建和同步检查。
- Windows 本机构建复用已安装、版本相同的 Electron 运行时，避免重复下载同一版本的运行时归档。
